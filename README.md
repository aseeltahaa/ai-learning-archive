## Overview

This repository aims to:

- build a strong foundation in machine learning theory
- understand the mathematics behind core algorithms
- practice clean Python implementations
- experiment with data preprocessing, visualization, and model evaluation

## How to Use this Repository
To run this project and experiment in this repo locally, follow these steps
1. Clone the repo
```bash
git clone https://github.com/aseeltahaa/classical-machine-learning
```
2. Navigate to the directory
```bash
cd classical-machine-learning
```
3. Create a Virtual Environment
```bash
python -m venv venv
```
4. Activate venv
On Windows: 
```bash
venv\Scripts\activate
```
On Linux/ MacOS:
```bash
source venv/bin/activate
```
5. Download Dependencies:
```bash
pip install -r requirements.txt
```
To run individual files:
```bash
python filename.py
```
