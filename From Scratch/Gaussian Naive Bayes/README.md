# Gaussian Discriminant Analysis (GDA)

Gaussian Discriminant Analysis (GDA) is a supervised classification algorithm that models how data are generated by assuming each class follows a Gaussian (normal) distribution and then uses Bayes' theorem to infer class membership.

---

## The idea

Instead of directly modeling $P(y \,|\, x)$ (the probability of the class given features), GDA models $P(x \,|\, y)$ (the probability of the features given the class) and combines that with the class prior $P(y)$ using Bayes' theorem:

$$
P(y\mid x)=\frac{P(x\mid y)\,P(y)}{P(x)}
$$

We compute the posterior for each class and choose the class with the highest posterior probability.

---

## Model assumptions

GDA assumes the following:

### Class distribution

The label $y$ follows a Bernoulli distribution (for binary classification):

$$
y \sim \text{Bernoulli}(\phi)
$$

where $\phi = P(y=1)$.

### Feature distribution

Conditional on the class, features are Gaussian with a class-dependent mean and a shared covariance:

$$
x\mid y=0 \sim \mathcal{N}(\mu_0,\Sigma),\qquad x\mid y=1 \sim \mathcal{N}(\mu_1,\Sigma)
$$

where $\mu_0$ and $\mu_1$ are the class mean vectors and $\Sigma$ is the shared covariance matrix. The covariance captures per-feature variances and feature correlations.

---

## Parameter estimation (training)

GDA parameters are obtained in closed form using maximum likelihood estimation (no gradient descent required).

### Prior

One common estimate for the class prior is

$$
\phi = \frac{1}{n}\sum_{i=1}^n y^{(i)}
$$

### Class means

The class mean vectors are the empirical averages of samples in each class:

$$
\mu_0 = \frac{\sum_{i:y^{(i)}=0} x^{(i)}}{\sum_{i=1}^n \mathbf{1}\{y^{(i)}=0\}},\qquad
\mu_1 = \frac{\sum_{i:y^{(i)}=1} x^{(i)}}{\sum_{i=1}^n \mathbf{1}\{y^{(i)}=1\}}
$$

These are the centers of each class.

### Shared covariance

The shared covariance matrix is estimated as

$$
\Sigma = \frac{1}{n}\sum_{i=1}^n (x^{(i)}-\mu_{y^{(i)}})(x^{(i)}-\mu_{y^{(i)}})^T
$$

This matrix measures how features vary together across all samples.

---

## Making predictions

After estimating $\phi$, $\mu_0$, $\mu_1$, and $\Sigma$, we compute class posteriors via Bayes' theorem and predict the class with the largest posterior. Equivalently, for binary GDA we can use the decision rule

$$
\hat y = \arg\max_y\, P(x\mid y)\,P(y)
$$

---

## Decision boundary

When the two classes share the same covariance ($\Sigma_0=\Sigma_1=\Sigma$), the decision boundary is linear. If the covariances differ ($\Sigma_0\neq\Sigma_1$), the boundary becomes quadratic (this variant is called Quadratic Discriminant Analysis, QDA).

---

## Advantages

- Works well when class-conditional distributions are approximately Gaussian
- Closed-form parameter estimates (no iterative optimization)
- Produces probabilistic outputs
- Can outperform logistic regression when its assumptions hold

---

## Disadvantages

- Assumes Gaussian feature distributions
- Sensitive to outliers
- Shared covariance assumption may be unrealistic
- Performance degrades when the data distribution deviates from assumptions

---

## GDA vs Logistic Regression

| GDA                       | Logistic Regression         |
| ------------------------- | --------------------------- |
| Generative                | Discriminative              |
| Models $P(x,y)$           | Models $P(y\mid x)$        |
| Assumes Gaussian features | No Gaussian assumption      |
| Closed-form solution      | Gradient-based optimization |

---

## When to use GDA

- Classification tasks where features are approximately Gaussian
- Small to medium datasets
- When you want probabilistic outputs
- When generative modeling assumptions are reasonable

---

## Intuition

Imagine each class produces a cloud of points. GDA learns where each cloud is centered ($\mu$), how spread out it is ($\Sigma$), and how common the class is ($\phi$). For a new point, GDA asks: "Which class most likely generated this point?"
